= TCK status
:description: Jakarta Expression Language 6.0 TCK — not run yet; the runner is milestone P8.

[.lead]
Honest status: the official Jakarta Expression Language 6.0 TCK has **not been run** against Peano.
The lexer, parser and AST are implemented, but the evaluator and `ExpressionFactory`
provider are still planned. The runner is milestone P8.

The `-Ptck` profile currently builds an empty runner and reports `No tests to run`.
A successful build of that profile is not a TCK pass.

== Plan of record

[cols="1,3",options="header"]
|===
| Item | Plan

| Runner | `peano-tck` module, in the reactor only under the `-Ptck` Maven profile (same pattern as the other Vidocq bricks); the official artefact is resolved only under `-Ptck,tck-official`.
| Artefact | `jakarta-expression-language-tck-6.0.1.zip` from download.eclipse.org. Embedded Maven metadata confirms `jakarta.tck:jakarta-expression-language-tck:6.0.1`; local installation is required.
| Test framework | JUnit Jupiter. Official cases are named `ELClientIT`; the runner must include `*IT` classes explicitly.
| Provider selection | Suite sources call `ExpressionFactory.newInstance()`.
| Container | Inspected standalone suite sources do not use Arquillian.
| Signature test | The distribution includes `ELSigTestIT`; its runtime setup still needs wiring.
| Script | `run-official-tck-el-6.0.sh` with `smoke` / `all` / `-Dtest=` modes, added with the first run.
| Merge gate | Once wired, 100 % PASS becomes a hard merge gate on `main`.
|===
