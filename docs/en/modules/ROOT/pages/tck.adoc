== Reproducing

[source,bash]
----
sdk env
./run-official-tck-el-6.0.sh all
./run-official-tck-el-6.0.sh smoke
./run-official-tck-el-6.0.sh '-Dtest=com.sun.ts.tests.el.spec.literal.ELClientIT'
----

The script downloads the official distribution if needed. Set EL_TCK_ZIP to an
existing 6.0.1 archive to avoid downloading it. It installs the unmodified jar with
controlled local metadata, builds the provider, then runs the selected official cases.
The full runner is never activated by a normal Maven build.

The upstream TCK is non-modular, so only its unpublished harness uses the classpath.
Independent named-consumer tests remain the authority for Java module encapsulation.
